# ☕ Exercícios de Programação Orientada a Objetos (POO) em Java

Repositório destinado ao estudo e prática de **Programação Orientada a Objetos (POO)** utilizando **Java**.

O objetivo deste projeto é consolidar conceitos fundamentais da orientação a objetos por meio da implementação de exercícios práticos, explorando recursos como encapsulamento, herança, polimorfismo, sobrescrita de métodos, abstração e outros pilares da POO.

> **Observação:** As implementações presentes neste repositório refletem meu processo de aprendizado. Algumas soluções poderão ser refatoradas ou aprimoradas conforme minha evolução nos estudos.

---

## 📂 Estrutura do Repositório

```text
.
├── README.md
├── conta_bancaria/
│   ├── ContaBancaria.java
│   ├── ContaEspecial.java
│   ├── ContaPoupanca.java
│   └── Main.java
│
├── exercicio_02/
├── exercicio_03/
└── ...
```

Cada pasta representa um exercício ou conjunto de exercícios, contendo suas respectivas classes e arquivos de execução.

À medida que novos conteúdos forem estudados, novas pastas serão adicionadas ao repositório.

---

## 🎯 Objetivos

* Praticar os conceitos de Programação Orientada a Objetos.
* Aprimorar a escrita de código em Java.
* Desenvolver soluções utilizando boas práticas de programação.
* Exercitar o raciocínio lógico e a modelagem de classes.
* Registrar minha evolução durante os estudos.

---

## 📚 Conceitos abordados

Ao longo dos exercícios, são praticados conceitos como:

* Classes e Objetos
* Encapsulamento
* Herança
* Polimorfismo
* Abstração
* Sobrescrita de métodos (`@Override`)
* Construtores
* Métodos e atributos
* Modificadores de acesso (`public`, `private`, `protected`)
* Métodos estáticos (`static`)
* Organização de pacotes

Novos conceitos serão adicionados conforme o avanço dos estudos.
